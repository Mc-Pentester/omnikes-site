# Site officiel OmniKès

Site vitrine public d'OmniKès, publié avec GitHub Pages.

## Contenu

- Présentation de la solution et de son approche local-first.
- Informations sur les fonctionnalités et le démarrage.
- Liens vers le dépôt principal et les versions officielles.

## Déploiement

Le workflow `.github/workflows/pages.yml` publie le contenu du dépôt sur GitHub Pages à chaque push sur `main`, ou à la demande via **Actions → Deploy OmniKès site → Run workflow**.

Dans **Settings → Pages**, sélectionner **GitHub Actions** comme source si GitHub le demande.

## Versions et installateurs

Les liens de téléchargement pointent vers les GitHub Releases du dépôt principal :

https://github.com/Mc-Pentester/omnikes/releases

Les installateurs ne sont pas construits par ce dépôt. Leur publication reste liée au processus de release du dépôt de l'application.

## Sécurité et données

Ce dépôt contient uniquement les fichiers publics du site. Ne jamais y ajouter de données clients, sauvegardes, secrets, clés, fichiers `.env` ou configurations privées.
